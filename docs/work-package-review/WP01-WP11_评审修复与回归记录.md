### REV-CONTRACT-001：契约检查依赖外部异源文件

- 复现：仓库真实 OpenAPI 为 479 操作，外部 SRS 文件为 481；旧检查没有固定仓库内权威来源。
- 根因：契约生成/核对和门禁没有统一使用仓库内的 OpenAPI 与操作映射。
- 修复：提交 `5befd82` 新增 `contracts/api-operation-map.json`；`scripts/check-openapi-contract.mjs`、`sync-api-mapping.mjs`、`tests/field-contract.test.mjs` 默认读取仓库内契约；`package.json` 的 `gate` 纳入 `contract:check`。
- 回归：`openapi-contract-check-result.json` 为 479/479，路由、方法、字段 Schema、查询参数、状态码均通过。
- 状态：已修复；CI 必须对最终 head 重跑。

### REV-UI-001：Ant Design Select 在 E2E 中选中不稳定

- 复现：虚拟列表、动画及隐藏下拉残留会导致点击未选中或误选。
- 根因：测试可定位不可见选项，引用数据未等待加载，且虚拟滚动限制选项渲染。
- 修复：`SchemaForm.tsx` 对枚举和引用 Select 设置 `virtual={false}`；`e2e/helpers.ts` 仅定位可见下拉、等待记录数、滚动后点击，并以键盘选择及选中值断言校验枚举。
- 回归：完整 Playwright Chromium 12/12、无跳过，覆盖桌面/移动表单与业务流。
- 状态：已修复；不把 Chromium 结果外推到 Firefox/WebKit 或实机。

### REV-E2E-001：长用例超过默认超时

- 复现：74 个真实创建页生命周期与桌面空表单用例超过旧默认测试时限。
- 根因：长链路测试未按真实执行规模设置专用预算，不是业务失败。
- 修复：创建生命周期测试设为 1,200,000 ms，桌面空表单契约设为 900,000 ms；没有跳过页面或缩短断言。
- 回归：完整 E2E 34.0 分钟；业务流 4.3 分钟、空表单 8.1 分钟、真实创建 12.9 分钟。
- 状态：已修复；长测试仍需 CI 的合理总超时支持。

### REV-AUTH-001：长 E2E 中访问令牌过期

- 复现：固定测试 access token 在默认 900 秒后返回 401。
- 根因：测试请求封装没有过期后的刷新与单次重试。
- 修复：`e2e/create-form-lifecycle.spec.ts` 的 `evaluateFetch` 遇到 401 后使用 refresh token 刷新会话并重试一次。
- 回归：完整生命周期 74 页通过；未移除认证、未跳过 401 断言。
- 状态：已修复；此修改仅完善测试客户端，不证明生产令牌配置已完成验收。

### REV-COMPOSE-001：随机密码与旧命名卷不匹配

- 复现：重复 Compose 验收时，新密码与保留 PostgreSQL 数据卷中的旧凭据不一致。
- 根因：每轮生成凭据但清理仅停止容器，没有同步清理专用验收项目卷。
- 修复：`scripts/p2-compose-acceptance.mjs` 在专用验收项目清理时执行 down 并删除项目卷；不影响用户其他 Docker 项目。
- 回归：`p2-compose-acceptance-result.json` 为 15/15 通过，覆盖配置、构建、down/up、健康检查、live/ready/web、重启和强制重建。
- 状态：已修复；该结果不是生产备份恢复或高可用证明。

### REV-WIP-001：本地工作树与远端基线不一致

- 发现：旧本地 HEAD、WIP 和 Codespace 分支引用混杂，不能直接认定最新修复已被评审。
