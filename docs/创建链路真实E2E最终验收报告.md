## 四、本轮关键修复

- 桌面/H5 使用真实 Schema 字段、控件、外键选项和必填校验，保存期间同步锁定，阻止双击重复提交。
- 登录公司目录改为真实 API 数据；公司主数据允许受权限控制地创建新公司编码，普通业务实体继续执行跨公司写保护。
- 修复枚举虚拟列表键盘选择、外键真实标签解析及 `Uom`/`Pack uom`、`Price`/`Price list code` 字段绑定歧义。
- E2E 种子同时建立 `THL`、`TGE` 真实公司，业务闭环可独立运行，不依赖其他用例先创建公司。
- 配送、财务、打印、库存 bigint 公司字段、只读会话吊销等均按真实服务规则适配，没有放宽业务断言。
- OpenAPI 删除系统留痕和认证会话的非法人工写操作，保留合法只读和受控动作契约。
